## 🚀 Tech Instagram Influencer Analysis (SQL Project)
## 📊 Project Overview

This project focuses on analyzing Instagram activity data to understand what drives reach, engagement, and follower growth.

The goal was not just to write SQL queries, but to extract meaningful insights that can help improve content strategy.

## 📌 Problem Statement

In the competitive social media landscape, understanding what drives reach, engagement, and follower growth is critical.

This project aims to analyze Instagram data to answer key questions such as:

- Which content types perform best?
- When does engagement peak?
- What factors influence follower growth?

The goal is to convert raw data into actionable insights for better content strategy.

## 🗂️ Dataset Description

## The dataset consists of three tables:

- dim_dates → Date-level information (month, week, weekday/weekend)
- fact_account → Profile visits and new followers
- fact_content → Post-level metrics like impressions, reach, likes, comments, shares, and saves
  
## 🔍 Key Analysis Performed
- Identified unique post types and compared performance
- Analyzed highest and lowest impressions
- Filtered weekend posts for March & April
- Evaluated monthly growth trends
- Used CTE to rank top-performing categories
- Measured reach contribution by post type
- Performed quarter-wise engagement analysis
- Applied window functions to identify top-performing dates
- Built a stored procedure for dynamic reporting

## 💡 Key Insights
- Certain post types contribute significantly to reach
- Engagement varies across months and content categories
- Timing and content strategy both influence follower growth

## 🎯 Recommendations
- Focus on high-performing post types to maximize reach
- Optimize posting schedule based on peak engagement periods
- Prioritize content categories that consistently perform well
- Balance content strategy to improve both reach and engagement
  
## 🎯 Conclusion
This project helped in understanding how data analysis can guide content strategy decisions, moving beyond just writing queries to interpreting business impact.
